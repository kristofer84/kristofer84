#### Selected repositories

**Networks and firmware**

- [**archer-mr600-openwrt**](https://github.com/kristofer84/archer-mr600-openwrt) — OpenWrt on the TP-Link Archer MR600 v1 (EU), with the built-in LTE modem working unattended. Prebuilt images plus a reproducible build kit.
- [**11r-monitor**](https://github.com/kristofer84/11r-monitor) — Real-time 802.11r fast-transition tracker for OpenWrt APs, with RRM and passive-capture RSSI positioning on a live property map.
- [**wpa8630-exploit-test**](https://github.com/kristofer84/wpa8630-exploit-test) — Firmware analysis of a TP-Link TL-WPA8630P v2, with an eye toward getting OpenWrt onto it.

**Reverse engineering and security**

- [**ghidra-arm64**](https://github.com/kristofer84/ghidra-arm64) — Headless Ghidra for arm64: builds the C++ decompiler from source and layers it in, so decompiles actually work on Raspberry Pi and Apple Silicon.
- [**process-credential-scanner**](https://github.com/kristofer84/process-credential-scanner) — Demonstrates that Edge keeps credentials in cleartext in process memory.

**Backend and tooling**

- [**mcp-postgres**](https://github.com/kristofer84/mcp-postgres) — MCP server for PostgreSQL, published on [npm](https://www.npmjs.com/package/mcp-postgres). Handles AWS RDS certificate setup automatically.
- [**dmarc-parser**](https://github.com/kristofer84/dmarc-parser) — Parses DMARC aggregate reports into a readable format.

**Smaller things**

- [**analog-timestamp-parser**](https://github.com/kristofer84/analog-timestamp-parser) — Extracts 7-segment-style timestamps from images (old digital cameras, CCTV).
- [**star-battle-solver**](https://github.com/kristofer84/star-battle-solver) — Solver for Star Battle puzzles.
